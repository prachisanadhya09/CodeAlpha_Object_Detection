# AI Object Detection and Tracking

## About Project
This project detects objects in images using Artificial Intelligence and YOLO.

## Technologies Used
- Python
- Streamlit
- YOLOv8
- OpenCV
- NumPy
- Pillow

## Features
- Upload images
- Detect multiple objects
- Display object names
- Show confidence scores
- Display detection results

## How to Run
1. Install required libraries.
2. Open the project folder in VS Code.
3. Run the command:

python -m streamlit run app.py

## Output
The system detects objects such as buses, cars, persons, motorcycles and backpacks.
